Storytelling Channels Uploader

Storytelling Channels Uploader is a private tool that Derek McConnell uses to upload and publish videos to YouTube channels he owns and manages. It is not offered to the public, and no one else signs in to it.

Privacy Policy

Last updated: September 30, 2026

What the app accesses. The app uses the YouTube Data API to upload videos, set thumbnails, and change a video's privacy status on channels owned by Derek McConnell. It only accesses the Google account that authorizes it.

What the app stores. The OAuth token Google issues at sign-in is stored only on the owner's personal computer so uploads can run on a schedule. The app does not collect, store, sell, or share any other personal data, and it does not access data from any other user.

Sharing. No data obtained through Google APIs is shared with or sold to any third party.

Google API Services. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time from the Google Account permissions page at myaccount.google.com/permissions.
